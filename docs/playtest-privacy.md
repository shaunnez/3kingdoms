# Playtest privacy note

For the private, invite-only THREEFOLD playtest ([deployment](deployment.md)).

- **Your address.** The server uses your IP address in memory to apply abuse limits, such as connections and new characters per address. Logs keep only a short salted tag, which changes whenever the server restarts. The hosting provider keeps logs for a limited time.
- **On the server.** Your character's name, guild, inventory, position and outlaw state are saved on a volume in Singapore. Daily backups are kept. Characters may be wiped at any time during the playtest.
- **In your browser.** An anonymous identity token and your invite key are kept in local storage. Clearing them loses access to that character.
- **Not collected.** There are no cookies, no analytics and no chat yet. When chat arrives, it will be logged, and this note will say so.
- **Your key is personal.** Don't share it; ask the host for another key instead. To have your character deleted, ask the host.
